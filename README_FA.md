# SMART MONEY AI ULTIMATE — نسخه اولیه قابل اجرا

این پروژه یک نمونه اولیه (MVP) است:
- اسکریپت Pine در TradingView شرایط تکنیکال را بررسی می‌کند و هشدار JSON می‌فرستد.
- سرور FastAPI هشدار را می‌گیرد و در SQLite ذخیره می‌کند.
- سرور RSSهای تنظیم‌شده را می‌خواند.
- اگر API Key هوش مصنوعی تنظیم شود، خلاصه محتاطانه فارسی از هشدار و تیتر خبرها می‌سازد.
- داشبورد موبایل در مسیر `/` نمایش داده می‌شود.

## پیش‌نیاز
Python 3.10 یا جدیدتر و یک سرویس میزبانی عمومی برای دریافت Webhook از TradingView.

## اجرای محلی
1. فایل `.env.example` را به `.env` کپی کنید.
2. `WEBHOOK_TOKEN` را به یک رمز طولانی و تصادفی تغییر دهید.
3. برای تحلیل AI، `AI_API_KEY` را وارد کنید. بدون کلید، دریافت هشدار و RSS همچنان کار می‌کند اما تحلیل AI غیرفعال است.
4. نصب وابستگی‌ها:
   `pip install -r requirements.txt`
5. اجرا:
   `uvicorn app.main:app --host 0.0.0.0 --port 8000`
6. داشبورد: `http://localhost:8000`

برای دریافت Webhook از TradingView، سرور باید با HTTPS و یک آدرس عمومی در دسترس باشد. آدرس محلی localhost برای TradingView قابل دسترسی نیست.

## اتصال TradingView
1. فایل `tradingview_smart_money_ai.pine` را در Pine Editor باز کنید.
2. مقدار ورودی Webhook token را دقیقاً برابر `WEBHOOK_TOKEN` قرار دهید.
3. اسکریپت را Save و Add to chart کنید.
4. در TradingView یک Alert بسازید؛ شرط آن نام همین اندیکاتور و گزینه `Any alert() function call` باشد.
5. در بخش Webhook URL، آدرس `https://YOUR-HOST/api/webhook` را وارد کنید.
6. Alert را ذخیره کنید.

## محدودیت‌های مهم
- Pine Script به تنهایی امکان درخواست آزاد HTTP به سایت‌های خبری یا مدل AI را ندارد؛ به همین دلیل تحلیل خبر و AI در سرور جدا انجام می‌شود.
- خبرها فقط از RSSهای تنظیم‌شده می‌آیند. کیفیت، تأخیر و مجوز استفاده از هر منبع را بررسی کنید.
- نمونه اولیه هنوز اسکنر مستقل همه نمادها نیست؛ برای هر نماد/تایم‌فریمی که می‌خواهید پایش شود باید نمودار و Alert متناظر بسازید، یا بعداً منبع داده بازار جداگانه اضافه شود.
- امتیاز سیگنال یک امتیاز تجربی است، نه احتمال موفقیت. پیش از استفاده واقعی، بک‌تست، paper trading و بررسی ریسک لازم است.
- این نرم‌افزار سفارش ثبت نمی‌کند و توصیه مالی نیست.

## امنیت
- `.env` را منتشر نکنید.
- از رمز Webhook طولانی استفاده کنید.
- برای استقرار واقعی، HTTPS، محدودسازی نرخ، احراز هویت و نگهداری امن کلیدها لازم است.
